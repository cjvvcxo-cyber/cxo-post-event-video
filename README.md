# CxO Direct Layout Editor v3

Replace the files in the GitHub Pages repository root with this package.

New direct-canvas controls:
- Click any image inside the layout to select it
- Drag the selected image to adjust the crop focal point
- Mouse wheel zooms the selected image
- Move selected image left or right within the scene
- Replace selected image from the full accepted image pool
- Toggle fit/fill
- Remove selected image from the scene
- Existing detailed slot editor remains available below the storyboard

Rendering remains local at 1080 x 1350. Use current Microsoft Edge or Google Chrome.
