# CxO Browser Video App

Static GitHub Pages app. Select a local folder containing originals and `(Custom)` resized copies. The app filters Custom files, previews multiple layouts and exports a 1080x1350 montage using the browser MediaRecorder.

## Deploy
Upload `index.html`, `styles.css`, and `app.js` to the repository root, replacing the existing files. GitHub Pages will redeploy automatically.

## Browser
Use current Microsoft Edge or Google Chrome. MP4 is used when supported; otherwise WebM is downloaded.
