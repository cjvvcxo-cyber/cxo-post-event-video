# CxO Smart Montage Studio v2

Upload these files to the root of the existing GitHub Pages repository, replacing the prior versions.

Features:
- Local folder selection
- Filters filenames containing `(Custom)`
- Reads image dimensions and classifies portrait, landscape, and square photos
- Orientation-aware scene building
- Real logo upload and render
- Logo positioning and sizing
- Scene storyboard
- Layout changes
- Image swapping
- Fill or full-image blurred-background crop mode
- Horizontal and vertical crop focal controls
- Browser export at 1080x1350

Use current Microsoft Edge or Google Chrome. MP4 availability depends on browser MediaRecorder support; otherwise WebM is produced.
